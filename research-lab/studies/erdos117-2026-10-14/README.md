# Erdős #117, 14 October 2026: 64 exact rank-five three-coordinate witnesses

Validity: EXACT_FINITE_CERTIFICATE for the explicitly named sample; ANALYTICAL_PROOF for the elementary group realization. Literature priority: PRIORITY_UNCHECKED. Lean formalization: UNFORMALIZED. **Neither the 3-coordinate class nor Erdős #117 is solved here.**

## Fixed question and evidence
Ask whether any faithful alternating map beta:F2^5 x F2^5 -> F2^3 has chromatic number strictly larger than clique number in its noncommuting graph. A sample cannot rule out a gap. We selected a reproducible, non-uniform set of 64 distinct 3-dimensional scalar spans using xorshift64* seed 0x5eed11720261014, skipping linearly dependent triples, duplicate spans and non-faithful maps. The selection produced 64 admissible triples in 64 attempts. Each has a matching clique and proper coloring with the same number k, independently checked using exact integer arithmetic.

The complete 64 witnesses are in certificates.txt, one line per input: sample_index, a, b, c, k, clique_mask, colors31. The ten bits of each scalar alternating form correspond to (i,j), 0<=i<j<5 in lexicographic order. Clique mask bit x-1 represents vector x, 1<=x<=31; the final 31-character string encodes colors 0..35 using digits 0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ. Every line has a k-clique and a legal coloring with exactly k colors. Thus omega>=k and chi<=k; the universal graph inequality omega<=chi forces omega=chi=k. No claimed optimality relies on an uninspectable solver flag.

## Genuine groups behind the records
For the vector-valued coefficients q_ij in F2^3, define f(x,y)=sum_{i<j} x_i*y_j*q_ij and multiplication (x,z)*(y,t)=(x+y,z+t+f(x,y)) on F2^5 x F2^3. Bilinearity proves the cocycle identity, so this is an associative class-two group. Its commutator is beta(x,y)=f(x,y)+f(y,x). Independence of the three scalar forms makes the derived subgroup all F2^3. Common radical zero makes the center exactly {0} x F2^3. Thus each input yields an actual group of order 256, center order 8 and derived subgroup order 8; its central quotient has dimension five. Abelian subgroup covers correspond to graph colorings, and pairwise noncommuting sets correspond to graph cliques.

## Mathematical limits and next decision
The 64 non-uniform samples, although exactly certified, cannot prove universal equality. The scalar spans are distinct, but need not yield distinct isomorphism classes. No uniform constant, finite threshold or h(n) inequality changes. The active next question is whether GL(5,2)-orbit classification reduces all faithful rank-five 3-planes to a small exact checkable list; a single exact chi>omega witness falsifies all-class equality.
