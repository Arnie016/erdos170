# Reproduction and evidence

## Formal layer

```
cd research-lab/lean
lake build
lake env lean OpenMath/Certificates.lean
```

The project pins Lean 4.19.0 and imports only Std. It has no Mathlib download requirement. The proof file uses kernel-reduced `decide`, not `native_decide`. The printed axiom report is part of the build evidence.

This layer initially formalizes explicit clique/isotropic-cover witnesses on F2^4 and the elementary product-noncommutation implication. It does not yet prove the entire group reduction or the large censuses in Lean.

## Computational layer

Recovered Python and C++ source is published with exact scope labels and fresh execution receipts. Large deterministic JSONL enumerations are regenerated by the source, rather than treated as opaque trusted solver output. Run each checker from its specified study directory. Exact commands and comparison checks are in the study documentation.

## Historical notes

Earlier exploratory calculations are not automatically accepted theorems. Their mathematical content may be useful, but every downstream theorem must identify its dependencies and checked scope. No public-source status is inferred from a failed website fetch.
